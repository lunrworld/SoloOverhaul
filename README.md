Solo Overhaul changes/overhauls/reworks/converts/modifies/alters the existing MMORPG game design of EFT into a single player game design for SPT.

## Features

- The Flea Market is disabled and its function has changed to act as a trader browser
- Instant hideout crafting and construction
- Insurance is removed

Credit to DanW's [Hardcore Rules](https://sp-mod.com/mod/784/hardcore-rules) mod, as his insurance removal code is used in this mod.
